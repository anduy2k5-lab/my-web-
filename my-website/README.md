# WEBSITE NGUYỄN DUY AN – BÀI TẬP HTML & CSS

## Nội dung
- Trang chủ: `index.html` (có ảnh cá nhân của học viên).
- Trang sở thích: `hobbies.html` (6 ảnh SVG tự thiết kế).
- Trang mục tiêu: `goals.html`.
- CSS: `style.css` và thư mục `images/`.
- Các trang cùng dùng CSS, có Skip to Main Content, Flex, Grid, hover, nth-child, và định dạng hình ảnh.

## Đăng lên GitHub Pages
1. Giải nén file ZIP. **Vào bên trong** thư mục `my-website`.
2. Trong repository GitHub, chọn **Add file > Upload files** và kéo các file `index.html`, `hobbies.html`, `goals.html`, `style.css`, và **thư mục `images`** vào trang upload (có thể kéo cả README.md và `.nojekyll`). KHÔNG upload file ZIP; KHÔNG bọc `index.html` trong thêm một thư mục.
3. Chọn **Commit changes** để lưu. Nếu repo đã có các file cũ thì phải cập nhật/thay thế bản cũ, không chỉ tải một ZIP lên.
4. Vào **Settings > Pages > Source: Deploy from a branch > Branch: main > /(root) > Save**. Nếu nhánh mặc định có tên khác, chọn nhánh đó.
5. Sau khi website được deploy, lấy link được hiển thị trong Settings > Pages; mở link và thử cả 3 trang.
6. Chạy W3C Validator và WAVE trên URL công khai; sửa các lỗi nếu có, rồi nộp link vào hệ thống lớp. Cuối cùng làm 3 bài đánh giá ngang hàng.

**Lưu ý:** Website công khai sẽ hiển thị ảnh chân dung của học viên. Chỉ đăng nếu học viên đồng ý công khai ảnh này.
